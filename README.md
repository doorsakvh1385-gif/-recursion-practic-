# GCD Recursive

This program calculates the Greatest Common Divisor (GCD) of two integers using recursion (Euclidean Algorithm).

Features:
- Uses a recursive method
- Includes a base case
- Takes user input from the console
- Prints the GCD

Example:
Input: 48, 18  
Output: 6
# Multiples of Three Recursive

This program prints all multiples of 3 that are less than a given number using recursion.

Features:
- Recursive method without loops
- Base case included
- Numbers printed in ascending order
- Takes user input from the console

Example:
Input: 20  
Output: 0 3 6 9 12 15 18
# Random Array Recursive

This program fills an array with random numbers and prints them.  
It can be implemented using recursion instead of loops.

Features:
- Recursive array filling method
- Recursive printing method
- User specifies array size
- Random numbers between 1 and 100

Example:
Input: 5  
Output: 23 67 4 99 12  (numbers vary every run)
